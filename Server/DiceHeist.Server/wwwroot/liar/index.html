함정 의자 라이어 다이스

컵 속 주사위로 허세 · 들키면 함정 레버 · 마지막 생존자가 판돈을 가져간다

로그인

가입하면 사이버머니 100,000을 드립니다. 방에 앉을 때 50,000을 테이블로 가져가고, 게임마다 참가비 5,000을 냅니다. 사이버머니는 게임 안에서만 씁니다(현금 거래 없음).

로비

    규칙 (1분)
    1. 모두 컵 안에서 주사위 5개를 굴립니다. 내 주사위만 보입니다.
    2. 차례대로 "테이블 전체에 ○ 눈이 △개 이상!"을 부릅니다. 앞 사람보다 높게(개수를 늘리거나, 같은 개수에 더 큰 눈).
    3. 1은 만능이라 어떤 눈으로도 셉니다. 부를 수 있는 눈은 2~6.
    4. 앞 사람 말이 거짓 같으면 "거짓말!" 모두 컵을 열어 셉니다. 틀린 쪽이 함정 레버를 당깁니다.
    5. 레버는 6칸 중 한 칸이 함정. 당길 때마다 떨어질 확률이 1/6 → 1/5 → … → 1로 오릅니다. 떨어지면 탈락!
    6. 마지막까지 의자에 남은 동물이 판돈을 가져갑니다. 이긴 사람은 금고 주사위로 두 배를 노릴 수 있습니다(4~6 두 배, 1~3 전부 잃음).
    7. 먼저 떨어진 사람은 남은 사람 중 누가 이길지 관전 베팅을 겁니다(생존자 수만큼 배당).
