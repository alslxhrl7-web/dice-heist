# 서버를 손대지 않아도 돌게 하기 (A부터 Z까지)

이 문서대로 하면 이 PC가 켜져 있는 동안 멀티 서버가 저절로 돌고, 밖에서도 `https://…ts.net` 주소로 들어올 수 있습니다.
순서: **1. 서비스 설치 → 2. 절전 끄기 → 3. Tailscale로 밖에서 접속**. 1번부터 차례대로 하세요.

---

## 1. 서버를 Windows 서비스로 설치하기

"서비스"는 Windows가 직접 켜고 끄는 백그라운드 프로그램입니다. 한 번 등록하면 PC를 켤 때마다 서버가 저절로 시작되고, 로그인하지 않아도 돌아갑니다. 서버가 오류로 꺼지면 Windows가 5초 뒤 다시 켭니다.

### 1-1. 준비 확인 (처음 한 번)

1. **Unity 에디터나 다른 창에서 서버를 켜 둔 게 있으면 끕니다.** Claude가 띄운 개발용 서버도 같은 번호(5080)를 써서 겹치면 서비스가 시작되지 않습니다. 지금은 꺼져 있습니다.
2. **인터넷이 연결돼 있어야 합니다.** 처음 빌드할 때 필요한 부품을 내려받습니다.

### 1-2. 관리자 권한 PowerShell 열기

서비스를 등록하려면 "관리자 권한"이 필요합니다. 일반 PowerShell로는 안 됩니다.

1. 키보드의 **Windows 키**를 누르거나 화면 왼쪽 아래 **시작 버튼**을 누릅니다.
2. 바로 `powershell`이라고 칩니다(검색창이 따로 없어도 그냥 치면 됩니다).
3. 검색 결과 맨 위에 **Windows PowerShell**이 나옵니다. 그 위에서 **마우스 오른쪽 버튼**을 누릅니다.
4. 메뉴에서 **관리자 권한으로 실행**을 누릅니다.
5. "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?"라는 파란 창(사용자 계정 컨트롤)이 뜨면 **예**를 누릅니다.
6. 파란(또는 검은) 창이 열리고, 창 맨 위 제목에 **관리자: Windows PowerShell**이라고 써 있으면 맞게 연 것입니다.
   - 제목에 "관리자"가 없으면 창을 닫고 3번부터 다시 하세요.
   - 맨 아래 줄은 `PS C:\WINDOWS\system32>` 처럼 보입니다. 정상입니다.

### 1-3. 저장소 폴더로 이동

창에 아래 한 줄을 **그대로 복사해서 붙여 넣고** Enter를 누릅니다. (PowerShell 창에서는 마우스 **오른쪽 클릭**이 붙여넣기입니다.)

```powershell
cd "$env:USERPROFILE\Documents\user\dice-heist"
```

- 성공하면 아무 메시지 없이 맨 아래 줄이 `PS C:\Users\mbc\Documents\user\dice-heist>` 로 바뀝니다.
- `경로를 찾을 수 없습니다`가 나오면 저장소 폴더가 다른 곳에 있는 것입니다. 파일 탐색기에서 dice-heist 폴더를 열고, 위쪽 주소창을 눌러 나오는 경로를 복사해서 `cd "그 경로"`로 실행하세요.

### 1-4. 설치 스크립트 실행

아래 한 줄을 붙여 넣고 Enter를 누릅니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\Server\deploy\install-service.ps1
```

- `-ExecutionPolicy Bypass`는 "이번 한 번만 이 스크립트 실행을 허용"한다는 뜻입니다. Windows 기본 설정이 스크립트 실행을 막고 있어서 붙입니다. PC 설정은 바뀌지 않습니다.
- 처음에는 1~3분 걸립니다(빌드). 그동안 창이 멈춘 것처럼 보여도 기다리세요.

**성공하면** 이런 줄들이 차례로 나오고 끝납니다.

```
빌드 중… (C:\DiceHeist\server)
서비스 등록…
완료: http://localhost:5080 에서 돌고 있습니다. (테스트 머니 버튼: False)
```

마지막 줄의 `완료:`가 보이면 설치가 끝난 것입니다.

### 1-5. 잘 됐는지 확인

1. **브라우저로 확인:** 크롬이나 엣지 주소창에 `http://localhost:5080` 을 치고 Enter. "다이스 하이스트" 소개 페이지가 나오고, **브라우저로 멀티 하기**를 눌러 로그인 화면(`/play/`)이 나오면 성공입니다.
2. **서비스 목록에서 확인:**
   1. Windows 키를 누르고 `서비스`라고 쳐서 나오는 **서비스** 앱을 엽니다.
   2. 목록에서 **Dice Heist 멀티 서버**를 찾습니다(이름순 정렬이라 D 근처).
   3. "상태"가 **실행 중**, "시작 유형"이 **자동**이면 맞습니다.
3. **재부팅 확인(선택):** PC를 다시 켠 뒤 아무것도 실행하지 않고 `http://localhost:5080` 이 열리면, 손대지 않아도 도는 것이 확인된 것입니다.

여기까지 됐으면 관리자 PowerShell 창은 닫아도 됩니다. 서버는 계속 돕니다.

### 1-6. 이럴 땐

| 보이는 메시지 | 원인과 해결 |
|---|---|
| `관리자 권한 PowerShell에서 실행해 주세요` | 일반 PowerShell에서 실행했습니다. 1-2부터 다시, 꼭 "관리자 권한으로 실행"으로 엽니다. |
| `…이 시스템에서 스크립트를 실행할 수 없으므로…` | 명령 앞의 `powershell -ExecutionPolicy Bypass -File` 부분이 빠졌습니다. 1-4의 줄을 통째로 다시 붙여 넣습니다. |
| `'dotnet' 용어가 cmdlet…으로 인식되지 않습니다` | .NET SDK가 없거나 경로를 못 찾습니다. 창을 닫고 새 관리자 창에서 `dotnet --version`을 쳐서 `10.`으로 시작하는 숫자가 나오는지 봅니다. 안 나오면 Claude에게 알려 주세요. |
| `빌드 실패` | 위쪽에 빨간 `error` 줄이 있습니다. 그 줄을 그대로 복사해서 Claude에게 보내 주세요. |
| `서비스는 시작했지만 응답이 없습니다` | 5080번을 다른 프로그램이 쓰고 있거나 서버가 시작하다 오류가 났습니다. 아래 "기록 보는 법"을 보고 내용을 Claude에게 보내 주세요. |
| `New-Service : 이름이 'DiceHeist'인 서비스가 이미 있습니다` | 예전에 등록한 서비스가 남아 있습니다. 같은 명령을 한 번 더 실행하면 "업데이트"로 처리됩니다. 그래도 안 되면 1-8의 지우기 후 다시 설치합니다. |

**기록 보는 법:** Windows 키 → `이벤트 뷰어` 실행 → 왼쪽에서 **Windows 로그 → 응용 프로그램** → 가운데 목록에서 "원본"이 **DiceHeist.Server** 또는 **.NET Runtime**이고 수준이 "오류"인 줄을 눌러 아래 내용을 복사합니다.

### 1-7. 코드를 고친 뒤 새 버전으로 바꾸기

**쉬운 방법:** 파일 탐색기에서 저장소 폴더의 `Server\deploy\update-service.cmd`를 **더블클릭**합니다.
1. "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜨면 **예**.
2. 검은 창에 "서비스 멈추는 중… → 빌드 중… → …"이 1~2분 흐릅니다.
3. 마지막에 "(테스트 머니 버튼: False)"가 보이고 "계속하려면 아무 키나 누르십시오"가 나오면 끝입니다. 아무 키나 눌러 창을 닫습니다.
4. 사이트를 **Ctrl+F5**로 새로고침해 바뀐 것을 확인합니다.

**PC 게임 내려받기 올리기:** Unity 메뉴 **DiceHeist → Windows 빌드**로 `Builds\DiceHeist-Windows.zip`을 만든 뒤 위처럼 업데이트하면, 스크립트가 그 zip을 `C:\DiceHeist\downloads`로 복사하고 소개 페이지에 **PC 게임 받기** 버튼이 나타납니다. zip이 없으면 버튼은 숨겨지고 "준비 중"으로 나옵니다.

**직접 하는 방법:** 1-2(관리자 PowerShell 열기) → 1-3(폴더 이동) → 1-4(같은 명령 실행)를 그대로 다시 하면 됩니다.

어느 쪽이든 서비스를 멈추고, 새로 빌드하고, 다시 켭니다. 계정·사이버머니가 든 DB는 지워지지 않습니다. 업데이트하는 1~2분 동안만 사이트가 꺼지고, 그때 멀티 테이블에 앉아 있던 사람의 stack은 서버가 다시 켜질 때 머니로 돌려줍니다.

### 1-8. 테스트 머니 끄기 · 서비스 지우기

- **테스트 머니 버튼**은 기본으로 꺼져 있습니다. 시험할 때만 켜려면 1-4 명령 끝에 ` -AllowGrant:$true`를 붙여 실행하고, 다 쓰면 붙이지 않고 다시 실행해 끕니다.
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\Server\deploy\install-service.ps1 -AllowGrant:$true
  ```
- **서비스 지우기:** 관리자 PowerShell에서 저장소 폴더로 이동한 뒤
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\Server\deploy\uninstall-service.ps1
  ```
  DB(`C:\DiceHeist\data`)는 남아서, 다시 설치하면 계정과 머니가 그대로 돌아옵니다.

### 설치되는 곳

| 경로 | 내용 |
|---|---|
| `C:\DiceHeist\server` | 서버 프로그램 (새 버전 설치 때마다 덮어씀) |
| `C:\DiceHeist\data\dice-heist.db` | 계정·칩·사이버머니. **이 파일이 가장 중요합니다** |
| `C:\DiceHeist\data\backups` | DB 사본. 서버가 켜질 때와 하루에 한 번 만들고 최근 7개만 남김 |
| `C:\DiceHeist\downloads` | 소개 페이지에서 내려주는 PC 게임 zip (업데이트 때마다 `Builds`에서 복사) |

## 2. 절전 끄기

PC가 절전 모드에 들어가면 서버도 멈춥니다. 모니터가 꺼지는 것은 괜찮습니다.

1. Windows 키 → 왼쪽의 **톱니바퀴(설정)** 를 누릅니다.
2. **시스템**을 누릅니다.
3. 왼쪽 목록에서 **전원 및 절전**을 누릅니다.
4. 오른쪽 **절전** 아래 "전원 사용 시 다음 시간이 지나면 PC를 절전 상태로 전환"을 눌러 **안 함**으로 바꿉니다.
   - 노트북이면 "배터리 사용 시" 항목도 있습니다. 서버로 쓸 때는 전원을 꽂아 두세요.
5. 설정 창을 닫습니다. 저장 버튼은 따로 없습니다.

## 3. 밖에서 접속하기: Tailscale Funnel

지금 서버는 이 PC 안에서 오는 접속만 받습니다(보안을 위해 일부러 그렇게 설정). Tailscale Funnel은 인터넷에서 오는 접속을 안전하게(HTTPS) 이 PC의 서버로 넘겨 주는 무료 프로그램입니다. 공유기 설정을 건드릴 필요가 없습니다.

### 3-1. Tailscale 설치

1. 브라우저에서 `https://tailscale.com/download` 를 엽니다.
2. **Windows** 다운로드 버튼을 눌러 설치 파일을 받습니다.
3. 받은 파일을 실행하고, 설치 창에서 **동의 → Install**을 누릅니다. 사용자 계정 컨트롤 창이 뜨면 **예**.
4. 설치가 끝나면 브라우저에 로그인 화면이 뜹니다. **Google, Microsoft, GitHub** 중 하나로 로그인합니다(무료 개인 요금제가 자동으로 만들어집니다).
5. "Connect device" 같은 확인 화면이 나오면 **Connect**를 누릅니다.
6. 화면 오른쪽 아래 작업 표시줄(시계 옆, 숨겨진 아이콘 `^` 안)에 Tailscale 아이콘이 생기면 설치 끝입니다.

### 3-2. Funnel 켜기

1. 이번에는 **일반 PowerShell**을 엽니다(Windows 키 → `powershell` → 그냥 클릭. 관리자 아니어도 됩니다).
2. 아래를 붙여 넣고 Enter:
   ```powershell
   tailscale funnel --bg 5080
   ```
3. **처음에는** "Funnel이 꺼져 있으니 이 주소에서 켜라"는 뜻의 영어 메시지와 `https://login.tailscale.com/…` 링크가 나옵니다.
   1. 그 링크를 복사해서 브라우저로 엽니다.
   2. 나오는 화면에서 Funnel(및 HTTPS) 사용을 **허용(Enable)** 합니다.
   3. PowerShell로 돌아와 같은 명령을 **한 번 더** 실행합니다.
4. 성공하면 대략 이런 내용이 나옵니다.
   ```
   Available on the internet:
   https://<PC이름>.<어떤이름>.ts.net/
   |-- / proxy http://127.0.0.1:5080
   ```
5. 이 `https://…ts.net/` 주소가 **친구들에게 줄 주소**입니다. 메모해 두세요.

### 3-3. 확인

1. 휴대폰의 **와이파이를 끄고**(LTE/5G로) 브라우저에서 그 주소를 엽니다. 로그인 화면이 나오면 밖에서도 접속되는 것입니다.
2. 지금 상태를 다시 보고 싶으면 PowerShell에서 `tailscale funnel status`.
3. 외부 접속을 끄고 싶으면 `tailscale funnel --https=443 off`.

`--bg`로 켠 Funnel은 Tailscale이 기억하므로, PC를 다시 켜도 저절로 다시 열립니다.

### 3-3-1. Windows에 로그인하지 않아도 열려 있게 하기 (무인 모드)

서버(DiceHeist 서비스)는 Windows 로그인과 상관없이 돕니다. 하지만 Tailscale은 기본 설정에서 **로그인한 사용자에 묶여 있어서**, 재부팅 후 로그인 화면에 머물러 있거나 로그아웃하면 바깥 주소가 끊깁니다. 무인 모드를 켜면 로그인 전에도 연결됩니다.

1. 작업 표시줄 오른쪽 아래 `^`를 눌러 **Tailscale 아이콘**을 오른쪽 클릭합니다.
2. **Settings**(설정) → **Run unattended**(무인 실행)를 눌러 체크합니다. 확인 창이 뜨면 **Yes**.
   - 메뉴에 없으면 일반 PowerShell에서 대신 실행합니다.
     ```powershell
     & "C:\Program Files\Tailscale\tailscale.exe" set --unattended
     ```
3. 확인: PowerShell에서 아래를 실행해 `"ForceDaemon": true`가 보이면 켜진 것입니다.
   ```powershell
   & "C:\Program Files\Tailscale\tailscale.exe" debug prefs | Select-String ForceDaemon
   ```
4. 진짜로 확인하려면 PC를 다시 시작하고 **로그인하지 않은 채로** 휴대폰(LTE)에서 주소를 열어 봅니다.

### 3-4. 이럴 땐

| 상황 | 해결 |
|---|---|
| `'tailscale' 용어가 … 인식되지 않습니다` | 설치 직후라 창이 경로를 모릅니다. PowerShell 창을 닫고 새로 연 뒤 다시 실행합니다. |
| 주소를 열면 "502" 또는 연결 오류 | 서버 서비스가 꺼져 있습니다. 1-5의 서비스 목록에서 **Dice Heist 멀티 서버**가 "실행 중"인지 보고, 아니면 오른쪽 클릭 → **시작**. |
| 휴대폰에서 안 열리고 PC에서는 열림 | 3-2의 허용(Enable)을 안 한 경우가 많습니다. `tailscale funnel status`에 "Available on the internet"이 있는지 봅니다. |
